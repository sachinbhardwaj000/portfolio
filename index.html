About Me

I'm Sachin, a web developer rooted in Palwal, Haryana, with a genuine love for building things that live on the internet. My journey into code started with curiosity and turned into a Bachelor of Computer Applications (BCA) degree from Amity University Online, Noida.

Since then, I've been sharpening my skills across the MERN stack — MongoDB, Express.js, React.js, and Node.js — while keeping HTML, CSS, and modern JavaScript (ES6+) as my foundation. I care about writing code that's clean, scalable, and built to actually work for real users, not just look good in a demo.

When I'm not coding, I'm usually exploring new tools, reading about system design, or rebuilding a favorite app from scratch just to understand how it ticks.
